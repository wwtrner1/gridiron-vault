Flag football coaching guide

Flag football install plan: 8 practices to game one

What to teach, in what order, so a new team is ready for its first game.

A new team can't learn 30 plays. It can learn eight to ten plays done well. This plan takes a flag football team from day one to game one in eight practices, adding one layer at a time so every new idea sits on something they already know. Each practice assumes about an hour.

  1. Practice 1: Stance, snap and flags

    Teach the stance, the center snap and the quarterback's grip. Play flag-pull tag for ten minutes so every player learns to pull flags and protect their own. End with the three words your team will use on every play: formation, play, snap count.

  2. Practice 2: The route tree

    Install three routes only: hitch, slant and go. Every receiver runs each one on air from both sides. The quarterback throws each route ten times. Number them so the call is one digit.

  3. Practice 3: First two plays

    Put the three routes into two plays from one formation: a quick game play (slants) and a high-low play (hitch with a go over the top). Walk it, jog it, then run it full speed against air.

  4. Practice 4: Reading man or zone

    Line up a scout defense in man, then zone. Send one receiver in motion: if a defender follows, it is man. Teach the quarterback one rule per coverage: against man, throw to the receiver who wins his break; against zone, throw to the receiver the defender leaves.

  5. Practice 5: Defense basics

    Install one man coverage (Cover 1) and one zone (Cover 2 or 3), plus the rusher's start on the rush line. Drill flag pulls on a ball carrier running at an angle, which is where most missed pulls happen.

  6. Practice 6: One run, one trick

    Add a handoff run to each side and one reverse or fake. Runs keep the defense honest so your passing plays stay open. Check the no-run zone rule so the offense knows where it must throw.

  7. Practice 7: Situations

    Red zone (no-run zone plays), fourth down, two-minute and the extra point. Build a call sheet with two plays per situation and run each one twice.

  8. Practice 8: Scrimmage and wristbands

    Scrimmage with real play calls from wristbands. Number the plays, call by number, and note which ones your players run cleanly. Those are your game one plays.

Rules that keep the install on track

  • Few plays, many reps. Two plays run twenty times beat ten plays run four times.
  • One formation first. Add a second only when every player knows where to line up without looking at the coach.
  • Same words every day. A route has one name and one number. Write them on the wristband the way you say them.
  • Teach the why. Tell players what each play does to the defense ("the slant beats the defender playing outside"), not just where to run.

Common questions

How many plays should a youth flag football team have?

Eight to ten for the first game is plenty: a handful of passing plays from one or two formations, one or two runs and a trick play. Add plays only when the first ones are run cleanly.

How long does it take to install a flag football offense?

About eight practices for a new team: stance and routes first, then two plays, then reading the defense, then situations and a scrimmage.

What should the first flag football practice cover?

Stance, the snap, flag pulling and the words your team will use to call plays. Keep it simple and keep everybody moving.
