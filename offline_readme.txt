GRID1RONVAULT PRIVATE PLAYBOOK — OFFLINE SITE

HOW TO OPEN
1. Extract the ZIP file to a folder.
2. Open index.html in Chrome, Edge, Firefox, or Safari.
3. Keep the cards folder, app.js, and styles.css beside index.html.

WHAT IS INCLUDED
- 56 source-derived route cards
- Search by play or formation
- Formation filters
- Full card previews
- Yellow Center with black C
- Black Quarterback with white Q
- Red RB with white lettering replacing orange Z
- Print layout sized to 4.5 × 2.02 inches

PRIVACY
This package runs locally and does not need to be published to the web.

PRINTING
Open a card, choose “Print this card,” and use 100% or Actual Size in the
browser print dialog. The print stylesheet is set to 4.5 × 2.02 inches.
